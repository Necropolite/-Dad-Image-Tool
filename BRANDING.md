# D.A.D. Branding

- **Brand:** D.A.D.
- **Meaning:** Dad's Automated Dropzone
- **Application:** Dad Image Tool
- **Tagline:** Drop • Archive • Deliver

D.A.D. does not download files from email or cloud services. The user downloads or saves the source item normally, then drops it into **Drop Client Pictures Here**. Dad Image Tool converts supported pictures to JPEG, archives successful originals, and routes unsuccessful items to **Needs Attention**.

The repository, executable, shortcuts, installation directory, and data directory retain their established names.
